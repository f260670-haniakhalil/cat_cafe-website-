# Meowcha Café Website

Meowcha Café is a multi-page static website for a cozy cat café, built using HTML and CSS. It lets visitors explore the café's menu, learn about its story and resident cats, and find contact details to plan a visit.

## Project Purpose

The purpose of this website is to promote Meowcha Café and give visitors the information they need before visiting. The website is designed for students, families, cat lovers and coffee enthusiasts who are looking for a calm and friendly place to relax.

## Design Theme

The website uses a soft **cream and pastel green** colour theme to create a warm, calm and welcoming feel. All pages share one stylesheet (`css/style.css`) so the colours, fonts and layout stay consistent.

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Welcome message, navigation menu, opening hours, session details, story preview and photo gallery |
| Menu | `[menu.html]` | Drinks, food and other services with images |
| About | `[about.html]` | The café's story and the cats |
| Contact | `[contact.html]` | Contact details and a contact form |

## How to Run the Website

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser (or use the Live Server extension).
4. Use the navigation menu to move between pages.
